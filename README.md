# HR-Analytics-Dashboard
HR Analytics Dashboard using Power BI to analyze employee data, demographics, and attrition.

HR Analytics Dashboard | Power BI

Project Overview

This project explores HR employee data through an interactive Power BI dashboard. It aims to make workforce information easier to understand and support data-driven HR analysis.

Objectives

- Analyze employee demographics and workforce composition.
- Explore employee attrition patterns.
- Summarize key HR metrics using KPI visuals.
- Present insights through charts and interactive visuals.

Tools Used

- Microsoft Power BI
- Power Query for data cleaning
- DAX for measures and calculations

Project Workflow

1. Imported the HR dataset into Power BI.
2. Checked missing values and data errors in Power Query.
3. Created DAX measures for employee metrics.
4. Built KPI visuals and charts for HR analysis.
5. Organized the report into a dashboard.
